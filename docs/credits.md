# Assets and dependencies

- Country boundaries: Natural Earth 1:110m, public domain, obtained from [globe.gl example datasets](https://github.com/vasturiano/globe.gl/blob/master/example/datasets/ne_110m_admin_0_countries.geojson). [Natural Earth terms](https://www.naturalearthdata.com/about/terms-of-use/). Generalized boundaries are cartographic context and not a statement on sovereignty. Dataset administrative names may be historical.
- Globe texture: `earth-dark.jpg`, from the [three-globe example assets](https://github.com/vasturiano/three-globe/blob/master/example/img/earth-dark.jpg). Project distributed under MIT; see bundled `THIRD_PARTY_NOTICES.md`.
- Typefaces: Geist and Geist Mono, provided by Next.js font integration and distributed under the SIL Open Font License.
- Interface icons: original inline SVGs authored for this prototype.
- Scenarios, chart series and reference observations: synthetic demo fixtures authored for this project. No upstream provider generated or verified these events.

The source references in the interface name intended future integrations only.
